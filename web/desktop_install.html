Как установить

WindowsMacТелефон

На Windows

  1. Скачайте установщикНажмите «Скачать для Windows» и дождитесь завершения загрузки.
  2. Откройте файл .exeОн появится в папке «Загрузки» вашего компьютера.
  3. Следуйте шагам установкиДождитесь завершения. Если компьютер принадлежит школе или организации, для установки может потребоваться помощь администратора.
  4. Откройте Аделию и войдитеНайдите приложение в меню «Пуск» и выберите свой кабинет.

На Mac

  1. Выберите свой процессорСкачайте .dmg для Apple Silicon или Intel. Это две разные версии.
  2. Откройте скачанный .dmgДождитесь, пока появится окно с приложением.
  3. Перенесите Аделию в «Программы»Перетащите значок приложения на папку Applications / «Программы».
  4. Запустите из «Программ»После копирования откройте Аделию оттуда. Образ диска можно извлечь через Finder.

Если возникли вопросы

Как войти родителю или преподавателю?

В приложении выберите нужный кабинет на стартовом экране. В браузере доступны кабинет родителя и кабинет преподавателя. Доступ определяется вашим аккаунтом.

Почему компьютер предупреждает о разработчике?

Сейчас доступны тестовые сборки без цифровой подписи. Windows или macOS могут показать предупреждение при первом запуске. Загружайте приложение с этой страницы. Если не уверены, что именно сообщает система, отправьте преподавателю снимок экрана — занятия доступны и через веб-кабинет.

Mac не даёт открыть приложение

Если предупреждение связано с непроверенным разработчиком и вы доверяете загруженному файлу, после попытки запуска откройте «Системные настройки» → «Конфиденциальность и безопасность» и подтвердите открытие именно Аделии, если такая возможность доступна. Подробная инструкция Apple ↗.

Если система сообщает о вредоносном ПО или повреждении файла, прекратите установку и сообщите преподавателю. Настройки защиты всего компьютера менять не требуется.

Нужен ли интернет?

Да. Приложение подключается к Аделии, чтобы показывать актуальное расписание, материалы и сообщения. Если соединение пропало, подключитесь к интернету и попробуйте ещё раз.

Файл не скачивается или не подходит устройству

Проверьте соединение, свободное место и выбранную версию. Для Mac важен тип процессора, а установщик Windows предназначен для 64-битной системы. При ошибке сообщите преподавателю название устройства и приложите снимок экрана. Пока можно пользоваться веб-кабинетом.
