# Веб-интерфейс «Аделии»

«Журнал» использует общие токены из `tokens.css`. Кабинеты собраны в `cabinet/` и
используют `cabinet.css` и компоненты из `cabinet/core.js`. Экраны со своими рабочими
сценариями, формы, документы и окна десктопа подключают `journal.css`.

| Поверхность | Вход |
|---|---|
| Публичная главная | `/app/landing-e.html` |
| Преподаватель | `/app/cabinet/teacher.html` |
| Ученик | `/app/cabinet/student.html` |
| Родитель | `/app/cabinet/parent.html` |

После входа по обычному веб-адресу открывается «Журнал» для своей роли.
Классический кабинет доступен из шапки или пункта «Ещё». Глубокие ссылки,
установленные PWA и Electron открывают прежние экраны с общими стилями.
Ученик и родитель переходят к специализированным действиям через существующие экраны.

Каталог `web/` отдаётся nginx под `/app/`. Для публичного лендинга
`landing-e.html` используется и в предпросмотре, и в корне сайта.
Переключение корня сайта выполняется отдельно от выкладки кабинетов
согласно разделу «Продакшн и деплой» в `CLAUDE.md`.

Для десктопа `desktop/sync_role_assets.js` копирует общие стили в пакет приложения.
