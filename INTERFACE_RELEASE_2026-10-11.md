# Интерфейсы Аделии · кандидат обновления

Изменения подготовлены в ветке `codex/desktop-beta-build-fixes`. Это не означает, что они уже установлены на сервере.

## Что изменено

- Общий логотип, SVG-иконки навигации и завершающий слой стилей для кабинетов ученика, родителя и преподавателя. Логотип также установлен на публичных страницах и страницах документов.
- Редактор аватара: 10 SVG-вариантов или собственное фото. Фото обрезается по центру до 256×256, очищается от метаданных и сохраняется в постоянной SQLite-базе. Доступ к фото: владелец, преподаватель, участники общей учебной группы для ученических аватаров. Публичной галереи личных фото нет.
- Групповой чат доступен ученику и преподавателю. Обновление раз в 4 секунды, сохранение текста при ошибке, защита от дубля при повторе отправки, режимы закрытого чата и объявлений. Поле ввода не пересоздаётся после сообщения. Вложения в групповом чате пока не добавлены.
- Родительский чат показывает вложения и хранит отдельные черновики для разных детей. Ошибки загрузки и отправки видны пользователю. Отметка прочтения ограничена последним полученным сообщением.
- В ученическом чате помощник свёрнут по умолчанию. Обновление истории не затрагивает поле ввода. Исправлены переходы между экранами, мелкий текст и расчёт доступной высоты.
- Время сообщений передаётся с явным часовым поясом; ученический и преподавательский интерфейсы используют выбранный регион. Родительский чат отображает локальное время устройства. Время занятия и его перенос — разные действия.
- Новая онлайн-оплата отключена. Сохранены существующие ручные платежи, проверка преподавателем, индивидуальные цены и отмена ошибочной отметки оплаты. Уже существующие подписанные callbacks прежнего провайдера оставлены для безопасного завершения старых операций.
- Десктопная версия `0.3.0-beta.2` включает общие компоненты. Это изменение исходников, а не готовые установщики.

## Проверки

```bash
python scripts/interface_release_selftest.py
python scripts/parent_message_scope_selftest.py
node scripts/student_messenger_selftest.js
node scripts/teacher_messenger_layout_selftest.js
```

Добавлена `.github/workflows/interface-check.yml`: реальный Chromium, размеры 390×844 и 1440×900, отправка/повтор группового сообщения, режим объявлений, выбор аватара, вложения и черновики родителя, чат преподавателя. Проверки используют вымышленные данные, не production API. Они не заменяют визуальную проверку всех экранов.

Локальный браузерный прогон заблокирован отсутствием Chromium в рабочем окружении. Перед production-переключением требуется успешная browser-проверка Actions и ручной просмотр на iPhone/Android и компьютере.

Последняя проверенная предыдущая сборка GitHub Actions: установщики Mac/Windows собираются, но загрузка артефактов не проходит из-за `Artifact storage quota has been hit`. Старые артефакты не удалялись. Освобождение квоты требует отдельного решения владельца.

## Безопасная выкладка

Рабочая конфигурация: `/opt/adelia-current`, API `127.0.0.1:8876`, основная БД `/opt/tutorbot/tutor.db`. Отдельная учебная БД доступна через `current/tutor.db` и не должна быть заменена основной базой.

До переключения: сохранить обе базы через SQLite backup API, зафиксировать текущую ссылку релиза, проверить постоянные пути БД всех шести служб. Экспортировать новый Git-коммит в отдельный каталог релиза, а не делать `git reset` или `git pull` в грязном `/opt/tutorbot`.

Сохранить существующие связи `tutor.db`, `storage`, `backups` и пути хранилищ из окружения. Не копировать незавершённый SQLite WAL как обычный файл. Не удалять старые релизы: часть данных всё ещё связана с ними.

После переключения: перезапустить службы, проверить `systemctl is-active`, `/api/health`, регистрацию через Telegram, загрузку фото/PDF, чаты по всем ролям, индивидуальную цену и ручное подтверждение/отмену оплаты. При ошибке вернуть предыдущую ссылку и перезапустить службы; не откатывать базу поверх новых пользовательских записей.

Перед выкладкой проверить опубликованные условия оплаты: они не должны обещать оплату через ещё не подключённую ЮKassa. Опубликованные документы в базе этим обновлением автоматически не изменяются.

## Не выдавать за завершённое

Это исправление основных компонентов, не утверждение об отсутствии всех ошибок во всём приложении. Не выполнены: сплошной визуальный аудит production, установка на реальном телефоне, публикация новых установщиков и переключение сервера. ЮKassa отложена по запросу владельца.
