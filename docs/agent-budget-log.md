## Главные советы
1. Сначала выяснить, какая ветка актуальна (потеряно ~125 тыс. на анализ устаревшего main).
2. Задачи на 50+ шагов дробить: часовые пояса и перенос стоило делить на 2–3 агента по ≤30 шагов.
3. Для документации и отчётов брать haiku с лимитом шагов: docs сделал 71 шаг вместо ~15.
