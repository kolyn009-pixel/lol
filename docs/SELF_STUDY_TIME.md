# Личное время на языки

Всем языковым аккаунтам доступен дневной бюджет от 15 до 180 минут целым
числом. Быстрые варианты: 15, 20, 30, 45, 60, 90, 120, 150, 180; точное значение
вводится в том же меню под вариантами. В опроснике также есть числовое поле.
Для четырёх выбранных языков минимум 20 минут (по 5 на каждый).

Профили без опросника больше не ограничены прежними режимами владельца
120/180 и семьи 60/90/120. Существующие значения этих режимов и распределения
сохранены. Остальные бюджеты распределяются с приоритетом английского;
после опросника используется выбранный главный язык. Сумма всегда равна
выбранному бюджету, каждый язык получает не меньше 5 минут.

Бюджет отдельный у владельца, ученика и родителя; рабочие занятия не меняются.
API проверяет границы и тип до записи. Время меньше минимума, дробь, bool и
строка отклоняются. Изменение обновляет полный overview, подбор новых занятий
и доступную дневную порцию слов. Уже начатый план сохраняется; сократить его
можно существующим коротким режимом. Сам бюджет не подтверждает уровень.

Проверки: сохранение/перезагрузка/точная сумма для трёх типов идентичности,
произвольный бюджет опросника, минимум четырёх языков, отказ без изменения
состояния. HTTP-прогон для teacher/student/parent и JS-сценарий ввода 105 минут.
Браузерная визуальная проверка пока не выполнена (Chromium отсутствует).
Установка — прежним install_self_study.py с резервной копией.
