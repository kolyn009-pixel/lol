# Семейные языковые курсы: состояние приёмки

27 октября 2026 года. PR #10 остаётся черновиком. Живой сервер не изменён.

## Исправлено после пяти проходов

1. Смена бюджета/дат возвращала обычный профиль без вычисленных полей
next_lesson/completed/total. Клиент использовал его как полный обзор и мог
упасть при выводе следующего урока. Теперь после сохранения загружается
полный обзор с защитой от устаревшего ответа.
2. Прежняя кнопка английской диагностики обновляла только старую таблицу.
Новая маршрутизация могла продолжать использовать старый placement.
Оба входа теперь сохраняют общую диагностику и пересчитывают маршрут,
сохраняя совместимый отчёт чтения и заданий речи.
3. Убрана фиксированная цель B2 к маю из экрана результата повторной
диагностики: применяются личные настройки. Подпись цели не называет
диагностику самооценкой.
4. Перенос кнопок бюджета и ограничение ширины текстовых полей добавлены
для небольшого экрана. Реальный визуальный результат ещё не проверен.

## Что выполнено

228 Python-тестов прошли. В HTTP-наборе 11 сценариев, включая полный путь
ученика и родителя через приглашение, обязательный тест, маршрут, диалог,
образец письма, аудирование, сокращение занятия и приватность.

Пять JS-сценариев: четыре проверяют фильтрацию своих ключей при очистке
IndexedDB; один исполняет настоящий self_study.js с минимальной заменой
DOM и проверяет повторную загрузку обзора после смены бюджета. Эти
замены не являются браузером, не проверяют layout, микрофон или IndexedDB
в реальном браузере. Синтаксис Python/JS и diff checks проходят.

## Что блокирует подтверждение готовности

Локальный Playwright не запускает Chromium: исполняемый файл отсутствует.
Последний GitHub Personal study checks 40544838479 завершился failure
до шагов (job 122332529711, runner_id=0, steps=[]). Причина не установлена;
это не означает, что тесты были выполнены или не прошли.

Не подтверждены браузерные сценарии, PWA/desktop, реальное воспроизведение
у издателей, микрофон, настоящий ИИ и установка на сервер. Нужно получить
работающий браузерный прогон, проверить функции в целевой среде, затем
использовать установщик с резервной копией и проверкой авторизации.

## Оставшиеся продуктовые пробелы

Первые блоки ступеней не составляют полный курс каждого уровня. FA B2/C1
ещё без материалов. Проверяемый банк аудирования содержит один EN-диалог;
остальные языки — управляемая самостоятельная практика у издателей.
Речь и письмо представлены образцами, самооценкой и необязательным
разбором расшифровки; независимая оценка этих навыков не реализована.
Ни одна из этих функций не подтверждает CEFR или срок достижения цели.
