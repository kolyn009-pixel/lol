# Учебные планы и результаты — 12 октября 2026

Эта ветка продолжает исправление регистрации `a303dbd225020df2b28184451eade6e0b479c987` и исправления чатов `387cd1e641d74dd01f9deb738d4e4111aa58f3ef`.

## Доступные функции

- Преподаватель составляет итог конкретного урока: разобранные темы, достижения и следующий шаг. Черновик остаётся у преподавателя; опубликованный итог доступен ученику и связанному родителю.
- Преподаватель ведёт темы для повторения с описанием ошибки, упражнением для закрепления и состояниями «Повторить», «В работе», «Исправлено».
- План по предмету содержит цель, дату и последовательность шагов. Процент отражает выполненные шаги, а не прогноз экзаменационного балла.
- Ученик оставляет пожелания в листе ожидания в своём часовом поясе. Преподаватель подбирает заявки по дате, предмету и полной длительности урока. Занятость проверяется перед предложением и согласием ученика.
- Предложение времени появляется в кабинете ученика. Оно не рассылает сообщения в Telegram/VK и не бронирует слот автоматически. После согласия ученика преподаватель оформляет запись обычным механизмом расписания.
- Поиск материалов учитывает русские буквы без различия регистра. Ученик получает только доступные ему материалы; локальные пути хранения не возвращаются.
- Точки входа: профиль ученика, меню «Ещё» преподавателя и карточки прогресса, кнопка «Учебный план» родительского кабинета.

## Совместимость

Используется текущий `web_backend.api_v7`; новый сервис не нужен. Таблицы создаются при первом обращении через существующий `database.connect`. Старые записи, цели и таблицы оплаты не изменяются. ЮKassa не подключается. Новые CSS/JS имеют версии для обновления браузерного кэша.

## Проверки

```bash
python scripts/learning_hub_selftest.py
node scripts/student_chat_draft_selftest.cjs
node scripts/group_chat_selftest.cjs
node scripts/onboarding_confirmation_selftest.cjs
python scripts/student_onboarding_start_selftest.py
```

Новые серверные проверки используют отдельную временную SQLite-базу и изолированные зависимости. Проверены скрытие черновиков, границы ученика/родителя, изменение состояния ошибки, сохранение плана при некорректной правке, русскоязычный поиск, часовые пояса, длительность и вызов проверки занятости.

Браузерный сценарий трёх ролей находится в `scripts/learning_hub_ui_selftest.cjs` и требует Playwright с установленным Chromium. В среде разработки браузер отсутствовал, поэтому визуальная проверка ещё не выполнена. Изменения не развёрнуты на рабочем сервере.

Перед развёртыванием необходимо сравнить текущий серверный релиз с этой веткой, сохранить резервную копию БД и выполнить проверки на копии. Затем проверить реальные входы трёх ролей, передачу файлов и текущие правила конфликтов расписания.
