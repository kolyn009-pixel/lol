# Документы и принятие родителями

Код подготовлен в PR. Сервер и юридические тексты этим коммитом не публикуются.

## Страницы

- `/app/legal.html` — общедоступные реквизиты, условия услуг, политика, отдельное согласие. Цены по ссылке `/#prices` берутся из существующего каталога.
- `/app/legal-admin.html` — редактор владельца; ссылка «Документы сайта» в кабинете преподавателя. Чтение черновика и публикация доступны только роли OWNER через авторизованный API.
- `/app/parent/consent.html` — родитель читает каждую редакцию по постоянной ссылке и отдельно отмечает принятие условий, ознакомление с политикой и согласие на обработку данных. Галочки изначально сняты; можно выйти без принятия.

Страницы используют существующий nginx alias `/app/` и `/api/`; новые nginx-маршруты не нужны. Backend и клиентские файлы обновляются вместе. Существующие реквизиты, если они есть только на сервере, нужно перенести вручную в редактор после проверки.

## Перед публикацией

Заполнить ФИО, ИНН, email, телефон и адрес для обращений. Проверка ИНН — только длина и контрольные цифры, не проверка владельца или статуса НПД.

В редакторе есть заготовки, а не готовое юридическое заключение. Владелец должен заполнить реальный порядок оплаты и выдачи чека НПД, условия переноса/отмены/возврата, состав и цели обработки данных, сроки хранения, внешние сервисы, права законных представителей и порядок отзыва согласия. Поля с `[Заполнить …]` не публикуются. Нельзя заявлять об автоматическом чеке или подключённой ЮKassa до их фактической настройки и проверки. Переключение платёжного провайдера на ЮKassa этим изменением не выполняется.

По предоставленной информации сервер находится в Нидерландах. До финализации политики нужно проверить фактическое размещение основной базы и файлов, применимость требований локализации и трансграничной передачи. Нельзя писать, что данные хранятся в России, без подтверждения. Текст согласия сам по себе не решает вопрос размещения данных.

Материалы для проверки:
- https://yookassa.ru/docs/support/payments/onboarding/arrangement
- https://publication.pravo.gov.ru/document/0001202506240021 — изменения об отдельном оформлении согласия (156-ФЗ от 24.06.2025).
- https://www.consultant.ru/document/cons_doc_LAW_61801/ — 152-ФЗ, в частности ст. 9, 12, 18.

Нажатие «Сохранить черновик» ничего не меняет для родителей. «Опубликовать» сохраняет неизменяемую редакцию и активирует обязательное принятие. Изменение общих тарифов само по себе не создаёт новую редакцию документов. Старые опубликованные версии остаются доступны по `?version=…`, поэтому не публикуйте лишние личные сведения.

## Запись и контроль

В рабочей SQLite создаются `legal_draft`, `legal_editions`, `legal_current`, `parent_legal_acceptances`. Редакция — SHA-256 канонического JSON всех документов и реквизитов. Запись содержит ID авторизованного родителя, редакцию, UTC-время и три отдельных подтверждения. ID из тела запроса игнорируется. Повторы идемпотентны. IP и User-Agent не собираются дополнительно.

Новая редакция проверяется в транзакции принятия: устаревший экран получает `documents_changed`. Доступ родителя к API кабинета/оплаты блокируется HTTP 428 до принятия; документы, авторизация и выход доступны. Проверка общая для API v7 и не полагается на галочки клиента. Провайдерский callback работает независимо. Данные уже ранее загруженного экрана не удаляются автоматически. Учёт согласий в Telegram/VK и отдельные согласия учеников этим проходом не реализованы.

До первой публикации запрос согласий выключен; публичная страница сообщает, что документы готовятся. Поэтому выкладка одного кода не означает готовность документов для заявки ЮKassa. Резервная копия основной SQLite включает редакции и подтверждения. Отдельного удаления/редактирования принятых редакций через UI нет. Отзывы согласий пока обрабатываются по указанному контакту вручную.

## Проверки

`python scripts/legal_documents_selftest.py` — реальная временная SQLite: закрытый черновик, валидация, отдельные подтверждения, смена редакции, изоляция родителей, параллельные повторы, CSRF и серверный запрет, тарифы 90 минут/отключение/колледж.

`node scripts/legal_ui_selftest.js` — Playwright с подставленным API: мобильная вёрстка, безопасный текст, незаполненные галочки, устаревшая редакция, переход после принятия и клиентский переход по 428. Это не проверка production.

В текущей среде браузерный прогон не выполнен: пакет Playwright есть, бинарник Chromium отсутствует. Синтаксис JS проверен; редирект общего обработчика дополнительно проверен через Node VM (`node scripts/legal_gate_selftest.js`). Перед публикацией требуется браузерный прогон.
