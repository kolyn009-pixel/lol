# Переносы и Google Календарь

Подготовлено 30 октября 2026 года. На сервер автоматически не устанавливалось.

- Уведомление преподавателю о прямом переносе через Telegram и заявка на своё время показывают имя, класс, предмет, исходные и новые дату и интервал, в московском времени. Неизвестный класс явно обозначается; значение не угадывается.
- Уведомления о применённом переносе/обмене из кабинета и Telegram содержат «Было / Стало». Кабинет ведёт по ссылке на новое занятие, а не на отменённую запись.
- Исправлен Telegram-обработчик, принимавший возвращённую строку нового занятия за числовой id.
- Google-событие включает класс и исходное время переноса. Будущее перенесённое занятие бирюзовое (цвет 7), с 🔁 в заголовке. Завершённость, ход занятия и срочная проблема оплаты имеют приоритет цвета.
- Синхронизация обновляет найденное событие, учитывает старый lessons.google_event_id, удаляет дубли с точным tutorbot_lesson_id. Отмена удаляет все связанные события, даже если id сохранился только в старом поле. Событие, уже переданное другому занятию, не удаляется.
- При ошибке Google id остаются для повторной попытки. Фоновая сверка учитывает старые записи, перенесённые в новые занятия, и связи из lesson_external_integrations. Существующий бот выполняет её каждые 5 минут, первый запуск после старта через 30 секунд. Сбой авторизации Google нужно исправить отдельно.
- Безымянные старые дубли без сохранённого id и без маркера Аделии автоматически не удаляются. Личные события и история реально проведённых занятий сохраняются.

## Установка

Из изолированной выгрузки этой версии, на сервере:

```
python3 scripts/install_reschedule_calendar.py --root /opt/adelia-current
python3 scripts/install_release_ui.py --root /opt/adelia-current
python3 scripts/install_reschedule_calendar.py --root /opt/adelia-current --apply
python3 scripts/install_release_ui.py --root /opt/adelia-current --apply
```

Первые две команды проверяют совместимость без изменения файлов. Не продолжать при ошибке. Установщик переносов применяет только проверенные фрагменты, сохраняет посторонние правки, делает резервную копию, перезапускает активные сервисы web / Telegram / VK и откатывает файлы при ошибке запуска. Данные занятий и токены не меняет. Мобильный интерфейс устанавливается отдельным проверенным установщиком после этой проверки. Эти два установщика имеют отдельные резервные копии.

После установки проверить реальный перенос тестового занятия: уведомление со старым/новым временем и классом, исчезновение старого события, одно событие на новой дате, повторная сверка без дублей. Провайдер Google и реальный сервер в этой среде не проверялись.

## Локальная проверка

`python3 scripts/reschedule_calendar_selftest.py`: 14 изолированных проверок SQLite и макета Google: очистка старых/канонических/dedup связей, чужое событие, 403 с повтором, отсутствие повторной вставки, класс/цвет/часовой пояс, обмен и фоновая сверка, подтверждение Telegram и ссылка на новое занятие из кабинета.

`python3 scripts/reschedule_install_selftest.py`: точность, повторная установка, сохранение посторонних изменений, отказ при конфликте.
