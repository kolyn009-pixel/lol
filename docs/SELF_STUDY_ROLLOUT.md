# Подготовленный выпуск семейных языковых курсов

Код в draft PR #10. Живой сервер/боты не обновлены. Семейная неделя ещё
не пройдена. Браузерный прогон не подтверждён. Не заменяйте весь рабочий
release содержимым этой ветки: используются точечные установщики.

## Пакет

Архив содержит явный список учебных исходников, тесты, документацию и
установщики. В нём нет базы, токенов, окружения или git-данных. MANIFEST.json
указывает исходный commit и SHA256 каждого файла. Контрольные суммы
обнаруживают повреждение, но не являются криптографической подписью автора.
Распакуйте в отдельный каталог исходников, не поверх рабочего release.

```sh
python scripts/build_self_study_bundle.py --verify .
python scripts/self_study_server_probe.py
```

Вторая команда только читает выбранные метаданные systemd-сервисов TutorBot/
Adelia: имя, PID, рабочий каталог и путь unit-файла. Она не печатает
окружение, токены, конфигурацию БД или пользовательские данные. По выводу
нужно подтвердить действующие WEB_SERVICE/LIVE_RELEASE/BOT_SERVICE/VK_SERVICE.
Реальный PRODUCTION_DB и порт LOCAL_API также подтверждаются отдельно;
скрипт их не угадывает. Не присылайте пароли или содержимое EnvironmentFile.

## Установка веб-раздела

Из отдельного каталога пакета, подставив подтверждённые значения:

```sh
python scripts/install_self_study.py --root "$LIVE_RELEASE" --database "$PRODUCTION_DB" --service "$WEB_SERVICE" --health-url "$LOCAL_API"
```

Это проверка без записи. После проверки совместимости и приёмки запускают
ту же команду с --apply. Установщик делает резервные копии базы/кода,
вносит только учебные hooks/assets, перезапускает выбранный веб-сервис,
проверяет health и 401 без сессии. Конфликт не обходить принудительным
перезаписыванием. Откат кода не подменяет живую базу. Подробнее SELF_STUDY_INSTALL.md.

## Боты: отдельное осознанное подключение

Новые команды: /languages, /language_today, /language_cards. Они отвечают
только на явную команду в личном чате, проверяют семейный доступ и показывают
только собственный профиль. Нет фоновых рассылок, автоприглашений или
замены рабочих меню. Обычные /start, ДЗ, оплаты и уведомления не меняются.

Telegram использует фактическую Telegram-привязку ученика/родителя/OWNER.
При двух ролях сначала предлагает выбрать свой профиль. Вход на сайт
остаётся обычным, с существующими кодами; семейное разрешение не выдаётся
командой и не заменяет авторизацию.

VK использует существующие подтверждённые связи channel_identities для
ученика и admin identity для OWNER. Для двух профилей можно указать
/languages teacher либо /languages student. Для родительских профилей
отдельная VK-привязка не обнаружена: бот не угадывает её и предлагает
сайт/Telegram. Это открытая часть интеграции VK родителей.

После установки веб-раздела проверьте каждый bot release отдельно:

```sh
python scripts/install_self_study_bot.py --root "$BOT_RELEASE" --service "$BOT_SERVICE"
python scripts/install_self_study_bot.py --channel vk --root "$VK_RELEASE" --service "$VK_SERVICE"
```

По умолчанию записи/перезапуска нет. Применение — с --apply. Установщик
проверяет точный hook, сохраняет резервную копию кода и не принимает
чужие изменения учебных модулей. При ошибке перезапуска возвращает код.
Откат по напечатанному каталогу резервной копии:

```sh
python scripts/install_self_study_bot.py --root "$BOT_RELEASE" --service "$BOT_SERVICE" --rollback "$BOT_BACKUP" --apply
```

Для VK тот же механизм, но указываются его release/service/backup. После
установки отдельно проверить статус сервиса и реальные ответы обеих ролей.
Реальные сообщения/боты в текущей среде не проверялись.

## Недельный пилот

В приложении: «Моя пробная неделя». Доступен приглашённым пользователям
ещё до стартового теста. Каждый запускает свою неделю сам. Семь реальных
календарных дней по Москве; будущие дни нельзя заполнить заранее. План:
тест/цель, занятие/пауза, карточки, аудирование, разговор, письмо, итог
четырёх навыков. Это рекомендации, выполнение не симулируется.

Личный отзыв: удобство 1–5, тяжесть нагрузки 1–5, потраченное время,
трудность/пожелание. День отдыха может иметь 0 минут. Данные доступны
только своему аккаунту; ни OWNER, ни остальные члены семьи не получают
сводку автоматически. Отзывы можно исправить с защитой от устаревшей
версии. Отзывы не повышают баллы и не подтверждают уровень.

Через неделю нужно реально обсудить собственные наблюдения и изменить
нагрузку/цели по желанию. Саму неделю нельзя выполнить кодом за один запуск.

## Наполнение и ограничения

К аудированию добавлена EN B2 лекция об эксперименте (два авторских
вопроса), полезная для академического языка и разговора о свойствах
материала. Проверено опубликованное содержание, не воспроизведение:
https://learnenglish.britishcouncil.org/free-resources/listening/b2/lecture-about-experiment
Исторические числа записи не подаются как актуальные сведения эксперимента.

DE A1: практикум Goethe с записью/решениями у издателя, без нашего
экзаменационного балла: https://www.goethe.de/ins/de/de/prf/gzsd1/ueb.html

Проверяемый аудиобанк теперь содержит две EN-записи. Это всё ещё не полный
банк всех уровней/языков. Полные курсы, FA B2/C1 и независимая проверка
речи/письма остаются открытыми задачами. Самооценка/разбор расшифровки
не называются независимой оценкой CEFR. Ненастроенный ИИ не симулируется.
