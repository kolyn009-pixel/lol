Подготовка релиза ведётся в PR #4. Production не обновлялся. Документы и новый порядок отмен ещё не объявлены действующими.

## Зафиксировано

Реквизиты и проект условий владельца подготовлены локально. Персональные реквизиты в GitHub не публикуются; можно ввести через OWNER-кабинет или приватный JSON ADELIA_LEGAL_DRAFT_FILE. Подробное согласованное решение: docs/APPROVED_CANCELLATION_RULES.md. ИНН прошёл проверку контрольных цифр. Для первого выпуска согласован бесплатный перенос/отмена не менее чем за 12 часов и ручное рассмотрение более поздних обращений. Проект шкалы 0/30/50/100% сохранён отдельно, автоматическое списание не включено.

## Уже подготовлено в коде

- Desktop/PWA интерфейсы для трёх ролей, встроенная переписка, серверная выдача файлов ДЗ через VK/TG, индивидуальные цены.
- Регион отображения преподавателя, точные моменты уроков, календарные дни в выбранном поясе; QR убран.
- Документы и реквизиты с черновиком/публикацией, OWNER-редактор, серверное принятие родителями с историей редакций.
- Публичный тариф учитывает сумму и длительность из кабинета, отключение и колледж.
- Реализована отключённая по умолчанию Robokassa, однако выбранным пользователем провайдером теперь является ЮKassa. Код Robokassa не считать подключением ЮKassa.

- 8 тестов SQLite документов/согласий/публичных тарифов, включая заполнение стартового черновика без перезаписи сохранённого.
