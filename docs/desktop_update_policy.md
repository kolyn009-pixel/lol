# Обновление Аделии

Изменения веб-интерфейса включаются в новые сборки Windows и macOS через sync_role_assets.js. После успешной сборки пакеты публикуются в существующие каналы /desktop-updates/beta/{win-x64,macos-arm64,macos-x64}/. Публикация сайта сама по себе не публикует приложение.

Клиент проверяет версию при запуске и каждые четыре часа. Пользователь выбирает скачивание, продолжая работу. Перезапуск требует отдельного действия и блокируется при активном занятии. Поддерживается частичная загрузка там, где её допускают платформа и артефакты; полный пакет остаётся допустимым резервным вариантом.

Сборки CI создаются как приватные draft releases. Их нужно проверять и публиковать на сервере существующим инструментом desktop_update_publish.sh. В конфигурации macOS пока отключена подпись. До настройки сертификата и проверки реальной установки нельзя считать автообновление macOS готовым. Сертификаты и серверные ключи не хранятся в репозитории.
