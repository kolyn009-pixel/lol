# Adelia TutorBot — Final Replace V2

Эта сборка предназначена для полной замены кода в `/opt/tutorbot` с сохранением серверных данных (`tutor.db`, `venv`, Google credentials, token.json, backups и `.env`).

## Исправлено главное

- Убран конфликт старого `students_admin` с новой карточкой ученика. Раньше callback `admin_students` перехватывался legacy-обработчиком, поэтому новая карточка из `admin.py` фактически не открывалась. Теперь список учеников ведёт в новую карточку Аделии.
- В новой карточке доступны `💬 Написать` и `💜 Спросить Аделию об ученике`.
- Исправлен вход `mh_write|ID` в ConversationHandler Аделии.

## Блокировка ученика

- `🚫 Заблокировать ученика` с подтверждением.
- Ученик получает уведомление о блокировке.
- Данные, история, занятия и баланс сохраняются.
- Заблокированный пользователь не может пользоваться TutorBot — глобальный guard останавливает его updates.
- `✅ Разблокировать ученика` восстанавливает доступ и отправляет уведомление.

## Канал

- Автоматических приветствий в канал нет.
- Бот тихо считает входы и выходы через `chat_member` updates.
- Каждый день в 08:30 администратору приходит: `пришло / ушло / изменение` за предыдущий день.
- Добавлена кнопка `💜 Подготовить пост с Аделией`.
- Администратор описывает идею обычными словами, получает AI-черновик и только после подтверждения публикует его в настроенный канал.

## Рассылки с Аделией

В главной админке добавлена `📣 Рассылка с Аделией`.

Сегменты:
- все активные ученики;
- ЕГЭ;
- ОГЭ;
- физика;
- химия;
- классы 5–11.

Сначала Аделия готовит черновик и показывает количество получателей. Реальная отправка происходит только по кнопке подтверждения.

## AI

OpenRouter используется только для языковых задач: понять запрос, подготовить/переписать сообщение, пост или рассылку. База, суммы, ученики, расписание и блокировки обрабатываются обычным Python-кодом.

При недоступном OpenRouter обычные функции TutorBot продолжают работать.

## Сводки и статистика

- Утренняя сводка: 08:30.
- Вечерняя сводка: 21:00.
- Недельная сводка: понедельник 09:00.
- Отдельный утренний отчёт канала по входам/выходам.

## Установка

Запускать из распакованной папки под root:

```bash
chmod +x deploy_to_opt.sh
./deploy_to_opt.sh
```

Установщик сам создаёт backup текущего `/opt/tutorbot`, сохраняет БД/venv/credentials, проверяет Python и перезапускает `tutorbot.service`.
