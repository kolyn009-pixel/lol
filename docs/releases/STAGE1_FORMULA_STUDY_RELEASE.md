# Этап 1 из 3 — Учебный центр и формулы

Основа: FINAL OPS + AI PROVIDERS.

Добавлено:
- `📚 Моя учёба` в главном меню ученика.
- `🧮 Формулы` на главном экране ученика.
- Автоматический старт с текущего класса ученика без ограничения доступа к другим классам.
- Физика и химия 7–11 классов из существующей библиотеки сохранены.
- Существующие формулы ЕГЭ и школьные справочники сохранены.
- Новый поиск по названию темы, величине, тексту и записи формулы; работает без AI.
- Карточки тем дополнены понятным объяснением и подсказкой «когда использовать»; исходная памятка остаётся видна.
- `⭐ Избранные` с хранением в БД.
- `🕘 Недавние` для быстрого возврата.
- `🧠 Проверить себя` без AI; статистика правильных ответов хранится в БД.
- Единые `⬅️ Назад / 🏠 Главная` в новых экранах.

Новые таблицы создаются идемпотентно и не затрагивают существующие данные:
- `formula_favorites`
- `formula_recent`
- `formula_quiz_stats`

Этап 2 будет связывать эту библиотеку с новым пошаговым мастером ДЗ преподавателя и выполнением ДЗ учеником.
