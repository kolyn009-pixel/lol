TutorBot - перенос и обмен (final exchange update)

Новый сценарий:
1. При переносе сначала показываются реальные свободные слоты.
2. Если ни один не подходит, доступна кнопка "Предложить своё время".
3. Пользователь вводит желаемые дату и время.
4. Если время вне рабочих часов преподавателя, запрос всё равно принимается и требует одобрения преподавателя.
5. Если слот свободен, преподаватель может подтвердить перенос.
6. Если слот занят другим учеником, после предварительного разрешения преподавателя второму ученику отправляется предложение обмена.
7. Если второй ученик согласен, преподаватель получает финальное подтверждение.
8. Только после финального подтверждения меняются времена занятий, обновляются Google Calendar и напоминания.
9. Родители с включёнными уведомлениями о расписании получают итоговые сообщения.

Админка:
Финальный центр -> Перенос / обмен -> ученик -> занятие -> свободный день/слот.
Если свободные варианты не подходят: "Предложить своё время".

Безопасность:
- Обмен не меняет минутный баланс и финансовые операции.
- Свободный перенос использует существующий database.free_reschedule_lesson().
- Обмен меняет только время двух подтверждённых занятий транзакционно.
- Старое расписание не меняется, пока не завершены необходимые согласования.
