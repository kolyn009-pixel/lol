# FINAL OPS + AI PROVIDERS

Добавлено:
- 📌 Рабочие задачи преподавателя без ИИ: ручные задачи + автоматические задачи по неоплатам, просроченным ДЗ и отсутствию следующего занятия.
- Кнопка задач в главном меню преподавателя и в карточке ученика.
- 🤖 Управление AI-провайдерами прямо из Telegram.
- OpenRouter остаётся текущим провайдером по умолчанию и продолжает читать ключ из /etc/tutorbot.env.
- Подготовлена возможность позже подключить Gemini, DeepSeek или другой OpenAI-совместимый API без пересборки бота.
- API-ключи дополнительных провайдеров хранятся в /etc/tutorbot_ai_providers.json с правами 0600, не в tutor.db и не в релизном архиве.
- Сообщение с новым API-ключом удаляется ботом best-effort сразу после чтения.
- Провайдер можно проверить, назначить основным, выключить или удалить прямо из бота.
- Если основной провайдер не отвечает, Аделия пробует следующий включённый.
- 📊 Счётчик успешных и ошибочных AI-запросов за день.
- Утренний/дневной/вечерний разбор, расписание, уведомления, CRM и задачи работают обычным кодом и не тратят AI-запросы без явного обращения к Аделии.
