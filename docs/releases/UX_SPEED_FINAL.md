# FINAL UX + SPEED

Добавлено перед финальной установкой:
- быстрые действия и настраиваемое избранное администратора;
- глобальный поиск из списка учеников;
- навигация класс -> ученики -> карточка с возвратом в класс;
- недавно открытые ученики;
- закреплённые ученики;
- компактная карточка ученика: основные действия сверху, редкие в «••• Ещё»;
- единые кнопки возврата/главной на ключевых экранах;
- счётчики во входящих/сообщениях главного меню;
- защита от повторного нажатия публикации канала и AI-рассылки;
- AI выполняется вне event loop, основной интерфейс не блокируется;
- индексы SQLite для учеников и занятий;
- агрегированный подсчёт классов в новой админской ветке вместо N+1 запросов;
- настройки уведомлений и UX сохраняются в БД.

Проверки: compileall, preflight_check, ai_assistant_selftest.
