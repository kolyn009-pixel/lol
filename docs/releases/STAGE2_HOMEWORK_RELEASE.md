# Stage 2 — Homework flow

- Teacher homework wizard: real 0–100% completion, 5 steps, autosaved DB draft.
- Assignment accepts text, one file/photo, several files, or text + attachments.
- Topic can be selected from any school grade; student's current grade is only the default.
- Optional review topic from a previous grade.
- Formula step is explicit: add formulas or consciously continue without them.
- Formula/topic search is local and does not use AI.
- Optional `Определить тему с Аделией` runs only by teacher action. PDF text is extracted best-effort; otherwise assignment text, caption and filename are used. Teacher always confirms the suggestion.
- Deadline presets and final preview are part of the wizard.
- Student homework screen keeps formulas available with the assignment. Opening a Telegram file sends the file and immediately places homework/formula controls below it.
- Attached formula cards can be expanded and collapsed without losing the homework context.
- Full formula library remains available even when teacher attached no formulas.
- Existing homework records remain compatible; Stage 2 uses additive tables only.
