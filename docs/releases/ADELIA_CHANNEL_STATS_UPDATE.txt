ADELIA / CHANNEL STATS UPDATE
=============================

Изменения:

1. Полностью убрано автоматическое приветствие новых участников в Telegram-канале.
   - удалена кнопка включения/выключения приветствия;
   - удалена отправка welcome-сообщений;
   - ChatMemberHandler теперь используется только для тихого подсчёта входов/выходов.

2. Добавлена ежедневная статистика канала для администратора.
   - каждый день в 08:30 по Europe/Moscow;
   - отчёт за предыдущий календарный день;
   - показывает «Пришло», «Ушло» и чистое изменение;
   - отчёт приходит только администратору, в канал ничего не публикуется;
   - сообщение отправляется и при нулевых значениях.

3. Добавлен журнал channel_member_events.
   - события JOIN / LEAVE;
   - хранится Telegram update_id для защиты от повторного подсчёта после перезапуска;
   - миграция совместима с существующей tutor.db.

Пример:

💜 АДЕЛИЯ • КАНАЛ

Доброе утро. Я посчитала изменения за 25.08.2026.

👋 Пришло: 7
🚪 Ушло: 2
📈 Изменение: +5

Важно: статистика начинает накапливаться после установки этой версии. Для получения chat_member событий бот должен оставаться администратором настроенного Telegram-канала.
