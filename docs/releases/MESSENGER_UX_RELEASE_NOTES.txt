TutorBot FINAL MESSENGER UX

Основные изменения:
- Полноценный мини-диалог преподаватель <-> ученик через TutorBot.
- У каждого сообщения преподавателя есть кнопка «Ответить преподавателю».
- Вкладка «Сообщения»: Новые / Все диалоги / Настройки сообщений.
- Непрочитанные сообщения и история диалога по ученику.
- Быстрые действия из диалога: ответить, карточка, записать, ДЗ.
- Отдельные часы приёма входящих сообщений преподавателем.
- Сообщение вне часов приёма сохраняется сразу и доставляется в ближайшие часы приёма.
- При отложенной доставке администратор видит фактическое время, когда ученик написал.
- Настройка дней приёма сообщений.
- Опциональные срочные сообщения.
- Исходящие сообщения преподавателя в тихие часы сохраняются в очереди и затем отправляются с кнопкой ответа.
- Компактное ученическое меню 2 колонки.
- Компактное административное меню 2 колонки.
- Все прежние функции и текущие серверные правки сохранены, так как релиз собран из фактического snapshot сервера.

Перед установкой обязательно проверить на копии живой tutor.db.
SERVER-архив не содержит tutor.db, token.json, credentials.json, venv и backups.
