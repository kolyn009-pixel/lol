TutorBot — обновление минутной модели

Что изменено:
1) Абонементы хранят и расходуют минуты, а не абстрактные занятия.
2) В покупке показывается привычный эквивалент «N занятий • X минут».
   Стоимость и скидка считаются от полного количества минут через индивидуальный тариф.
3) Для каждого направления ученика есть individual default_duration_minutes.
   Из карточки ученика: «Основное время занятий» → 60/75/90/105/120/150/180 минут.
4) При разовой записи ученик может выбрать основное время или больше, но не меньше.
5) При записи плановые минуты резервируются. Переработка преподавателя не списывает лишние минуты.
6) Недоработанные преподавателем минуты сразу начисляются в бонусную копилку и расходуются первыми.
7) Главное админ-меню: единые «Входящие» + отдельные «Сообщения от учеников».
8) Сохранены предыдущие правки: строгая финансовая аналитика по finished_at, кнопка управления балансом,
   удаление отменённых Google Calendar событий; HTTP 410 от Google считается уже удалённым событием.
9) Цепочка напоминаний сохранена: 24ч / 2ч / 30мин / 10мин.

Безопасное обновление сервера:
- обязательно сделать backup tutor.db;
- заменить код SERVER-архивом, не затирая tutor.db/token.json/credentials.json/venv;
- выполнить: ./venv/bin/python minute_model_selftest.py
- выполнить: ./venv/bin/python -m compileall -q .
- затем systemctl restart tutorbot и проверить journalctl.
