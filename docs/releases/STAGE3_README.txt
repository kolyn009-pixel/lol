TUTORBOT STAGE 3 — AUTOMATION & FAMILY

Новые модули:
  automation/schema.py              — миграции Stage 3
  automation/waiting_list.py        — лист ожидания
  automation/balance_forecast.py    — прогноз остатка занятий
  automation/notifications.py       — настройки уведомлений родителей
  automation/family.py              — семейный кабинет
  automation/messaging.py           — обращения, рассылки, отложенные сообщения
  automation/referrals.py           — реферальные коды
  automation/student_history.py     — единая история ученика
  automation/schedule_tools.py      — паузы, больничные, группы
  automation/operations.py          — «Сегодня» и внимание
  automation/jobs.py                — фоновые задания
  handlers/stage3_handlers.py       — Telegram handlers Stage 3
  repositories/automation_repo.py   — слой доступа к новым данным

Команды:
  /ops                           операционный помощник администратора
  /waitlist [комментарий]        ученик: лист ожидания
  /balanceforecast               ученик: прогноз баланса
  /family                        родитель: семейный кабинет
  /referral                      ученик: реферальный код
  /claimref CODE                 ученик: применить код
  /question TEXT                 ученик/родитель: организационный вопрос
  /history STUDENT_ID            админ: история ученика
  /pause ID FROM TO [причина]    админ: пауза регулярного расписания
  /absence FROM TO [причина]     админ: недоступность/больничный (без автоудаления)
  /broadcast TEXT                админ: массовая рассылка с подтверждением
  /schedulemsg DATE TIME | TEXT  админ: отложенная массовая рассылка

ВАЖНО:
- Массовая отмена при больничном намеренно не выполняется без подтверждения.
- Старые формулы и библиотеки Stage 2 сохранены без изменений.
- Один tutor.db; новые таблицы добавляются миграцией без удаления старых данных.

Дополнительные команды Stage 3:
  /notifysettings [STUDENT_ID]     родитель: 24ч/2ч/30м/10м и другие уведомления
  /tag STUDENT_ID TAG             админ: тег ученика
  /template NAME | TEXT           админ: сохранить шаблон
  /templates                      админ: список шаблонов
  /period NAME FROM TO            админ: учебный период
  /monthlyreport ID [YYYY-MM]     админ: отчёт родителю с подтверждением отправки
  /broadcastto SEGMENT | TEXT     админ: сегментированная рассылка (all, grade:N, subject:CODE)

Интеграция с предыдущими этапами:
- Stage 1: роли, аудит, финансовый журнал, диагностика, backup, события, финансовая аналитика.
- Stage 2: программа обучения, диагностика, пробники, цели, слабые темы, предурочная сводка, формулы.
- Stage 3: автоматизация и семейные сценарии.

Регулярные занятия:
- существующий генератор на 28 дней сохранён;
- новые занятия не должны оставаться активными в период паузы ученика/недоступности преподавателя.

Родительские напоминания:
- по умолчанию 24ч + 2ч включены;
- 30м + 10м выключены;
- настраиваются отдельно для каждого ребёнка.
