Удаление старой Аделии в Windows

1. Закройте старую Аделию, в том числе через значок возле часов.
2. Откройте PowerShell в этой папке.
3. Для просмотра найденных установок выполните:
   .\Remove-Old-Adelia.ps1 -ListOnly
4. Для удаления выполните:
   .\Remove-Old-Adelia.ps1
5. Выберите номер именно старой установки. Откроется её штатный мастер удаления.

Утилита не удаляет папки вручную и не меняет серверные данные.
Версия 0.3.0-beta.3 и неизвестные версии исключены из выбора.
Если Windows запрещает запуск скриптов, откройте Параметры → Приложения → Установленные приложения и удалите старую Аделию там. Менять политику выполнения не требуется.
Если первая версия была переносимой либо зарегистрирована под другим названием, утилита ничего не удалит и откроет список приложений Windows.
Самая ранняя найденная регистрация не обязательно является самой первой выпущенной версией. Сверьте показанные дату, путь и версию перед выбором.
